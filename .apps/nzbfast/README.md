## Description

[nzbfast](https://nzbfast.github.io/nzbfast/) is a Usenet downloader built around a single pass: every byte gets decoded, verified and extracted while it downloads. There's no assembly pass afterwards, nothing left to verify or unpack once it's done. The moment the progress bar fills, the file is finished and provably intact.
