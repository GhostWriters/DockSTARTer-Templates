## Description

[Music Assistant](https://music-assistant.io/) is a music library manager that connects your streaming services and local music files to connected speakers and media players, including Sonos, Google Cast, AirPlay, DLNA, and Home Assistant.

## Install/Setup

Music Assistant uses network autodiscovery to find and stream audio to players on your local area network. Host networking (`network_mode: host`) is recommended.

Once started, access the initial configuration and setup wizard at `http://<server-ip>:8095`.
