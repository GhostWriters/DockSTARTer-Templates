## Description

[Crafty Controller](https://craftycontrol.com/) is a next-generation web-based control panel for launching, monitoring, and administering Minecraft Java and Bedrock dedicated servers.

## Install/Setup

Access the web interface at `https://<server-ip>:8443` (or `http://<server-ip>:8000`).

On first launch, check the container logs (`docker logs crafty`) to retrieve the generated default administrator credentials.
