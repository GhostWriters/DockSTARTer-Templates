## Description

[Forgejo](https://forgejo.org) is a self-hosted lightweight software forge, a community fork of Gitea. It is published under the GPLv3+ license.

## Install/Setup

Forgejo does not publish a `latest` container tag, so the template defaults to
the current major release tag (e.g. `15`), which receives patch updates
automatically. See the [Forgejo release notes](https://forgejo.org/releases/)
when moving to a newer major version.

For further configuration see the
[Forgejo documentation](https://forgejo.org/docs/latest/admin/). If you need
assistance setting up this application please visit our
[support page](https://dockstarter.com/basics/support/).
